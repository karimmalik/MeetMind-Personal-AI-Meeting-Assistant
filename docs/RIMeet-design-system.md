# RIMeet design system

## Typography

| Use | Font | Examples |
| --- | --- | --- |
| UI and content | Manrope | Headings, navigation, buttons, labels, inputs, transcript, body copy |
| Metadata | DM Mono | Eyebrows, status pills, timestamps, versions, technical identifiers |

Fonts are bundled locally. The standard is enforced through `--font-ui` and `--font-meta` in `desktop/src/typography.css`.

## Visual direction

Warm cream base with soft orange accents and low-contrast neumorphic surfaces. New UI should use the existing CSS variables/tokens and match the visual weight of the current application.
